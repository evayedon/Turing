# Research environment and methodology

**Executive judgment.** Turing has the right ownership boundary for a desktop IDE. Its next constraint is the lack of versioned project and document context shared by diagnostics, navigation, execution and future AI. Build a vertical slice from an authorized saved document through a managed language server to Problems before widening project execution or agent authority.

Static assessment used REA CLI and MCP bundle-resource tools, `file`, `otool -L`, `PlistBuddy`, version probing, and Xcode bundle component inventory. Initial native helper access failed in the workspace sandbox; the approved CLI invocation succeeded. No configuration changes or access-control bypasses were used. Full REA records were placed in temporary host storage rather than committing large installed-package-derived artifacts. Evidence IDs and input identities support re-running the selected inspections.

**Confidence convention:** High means direct source, official documentation or observed metadata for the stated scope. Medium applies to inferences anchored in multiple observations. Open means the study did not establish the claim. Future validation should use synthetic projects, fixtures without credentials, unmodified installations, and supported observation mechanisms. The VS Code bundled CLI also returned the installed version, product commit and arm64 when run with `--version`. It emitted a sandbox-related process identity diagnostic during the probe. Native editor interaction/VoiceOver, performance and memory comparisons, Windows/Linux behavior, deeper Xcode internals and live cloud/AI workflows remain unverified.

Reproduction requires REA 6.9.0 and its compatible Node, as reported above. In the following examples, `rea` means the configured package entry run with that Node. Each CLI output path should be new.

```sh
rea doctor --client codex --json
rea providers --json
rea inspect-macho /Applications/Xcode.app/Contents/MacOS/Xcode --json
rea analyze-javascript-application '/Applications/Visual Studio Code.app/Contents/Resources/app' \
  --source-path out/mainImpl.js --integrity-policy record-and-continue \
  --evidence_output /tmp/turing-vscode-main-reproduction.json --detail summary --json
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -version
```

For resources, initialize the registered stdio process, list tools, open `/Applications/Xcode.app` with `open_bundle_resources`, then call `inspect_plist` on `Contents/Info.plist` using its absolute path and reset the session with a checkpoint. Match these findings by target identity, tool version and coverage in addition to Evidence IDs. Do not use an integrity contradiction as proof of tampering, authenticity, or operational safety.
