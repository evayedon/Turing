# UI, accessibility and developer workflows

| Reference workflow                                                                                                                                                          | Evidence and confidence                                                                                                                                                                                                                                    | Turing design and test                                                                                                                                                                           |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| VS Code exposes the same commands through contextual menus, keybindings and a searchable palette; layout, profiles and settings offer composition.                          | High. [User interface](https://code.visualstudio.com/docs/getstarted/userinterface), [keybindings](https://code.visualstudio.com/docs/configure/keybindings)                                                                                               | Keep Nebula tokens and original layout. Make commands searchable by intent and explain availability. Test keyboard-only editor, pane, tab and terminal traversal at narrow widths.               |
| Issue and Report navigators in Xcode support source feedback and historical build/test investigation.                                                                       | High for documented workflows. [Xcode docs](https://developer.apple.com/documentation/xcode)                                                                                                                                                               | Build persistent, clearly separated live diagnostics and run history using common source links. Verify cancelled attempts and failed tests remain identifiable.                                  |
| VS Code supports Git, testing UI and extension-driven commands; Xcode integrates Git, tests, destinations and archives.                                                     | High. [VS Code Git](https://code.visualstudio.com/docs/sourcecontrol/overview), [VS Code tests](https://code.visualstudio.com/docs/debugtest/testing), [Xcode tests](https://developer.apple.com/documentation/xcode/organizing-tests-to-improve-feedback) | First deliver diff/status, test discovery and source-linked failure results. Keep credentials and push separate from file access. Verify status on dirty, renamed, ignored and conflict entries. |
| Screen reader optimizations, keyboard access and terminal accessibility are documented VS Code surfaces. Xcode runs on macOS; specific VoiceOver behavior was not observed. | High for VS Code docs; open for Xcode runtime parity. [VS Code accessibility](https://code.visualstudio.com/docs/configure/accessibility/accessibility)                                                                                                    | Test VoiceOver, NVDA and Orca focus order, contrast, zoom, announcing diagnostics and streamed terminal output under burst loads.                                                                |
| Copilot agent integrations expose multiple workflows. Xcode product material describes coding intelligence.                                                                 | High for advertised surfaces. [VS Code agents](https://code.visualstudio.com/docs/copilot/agents/overview), [Xcode](https://developer.apple.com/xcode/)                                                                                                    | Make agent work visibly distinct from user actions. Attach context manifests, diff review and verification receipts. Test revoked approval, model outage and private files.                      |

Suggested comparative task script uses the same synthetic repository: open, rename a symbol, inspect a compiler error, fix one issue, run one failed test, navigate to output, stage a partial diff and recover a dirty session. Record action count, focus losses, incorrect affordances, and time separately. Use native accessibility APIs only with available authorization.
