# Xcode architecture

The installed Apple product is Xcode 27.2, build 27B52. Local bundle evidence identifies an arm64 launcher linked to AppKit, Foundation, Objective-C, libSystem and CoreFoundation. The bundle contains separate editor, build support, debugger, previews, test UI, source control and Interface Builder components. Names establish packaging boundaries. Service lifetime, message formats, object ownership and threading remain open.

## Toolchain and product handoffs

| Handoff                             | Evidence, confidence and Turing implication                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Clang compilation context           | LLVM documents a JSON compilation database that associates source files with directories and command/argument sets. High for the format. Preserve source–target associations for C++ navigation and avoid executing commands solely because a database contains them. Verify the same C++ file can have distinct flags per target. [Clang compilation database](https://clang.llvm.org/docs/JSONCompilationDatabase.html)                                                                                                                                  |
| Swift package dependencies          | Apple documents adding packages to projects. High for the workflow. A project adapter should preserve package lock and toolchain identity and require explicit approval for dependency fetching. Verify resolved and offline behavior independently. [Package dependencies](https://developer.apple.com/documentation/xcode/adding-package-dependencies-to-your-app)                                                                                                                                                                                       |
| Preview, resources and destinations | Apple documents preview workflows and simulator management. High for documented capabilities; private preview transport remains open. Keep previews disposable and separate simulator/device authority from a source grant. Verify close kills a fixture runtime and that a missing destination is actionable. [Previews](https://developer.apple.com/documentation/xcode/previewing-your-apps-interface-in-xcode), [Simulator](https://developer.apple.com/documentation/xcode/managing-simulator-devices)                                                |
| Reports and release                 | Installed Developer tools include `xcresulttool`, `xctrace`, `simctl`, `xcdevice` and `lldb-dap`; presence does not establish successful execution. High for inventory. Use artifact IDs and public command surfaces for integrations. Verify old result bundles remain visible and signing credentials stay outside run logs. [Test results](https://developer.apple.com/documentation/xcode/running-tests-and-interpreting-results), [distribution](https://developer.apple.com/documentation/xcode/distributing-your-app-for-beta-testing-and-releases) |
| Extension boundary                  | XcodeKit documents source-editor extensions. High for exposed API and insufficient evidence for a general workbench host. Version Turing's first narrow contribution interfaces and test compatibility independently from native app versions.
